CLIENTPLATFORM BOTFATHER CONFIG

/setname
ClientPlatform

/setabouttext
ClientPlatform — цифровой сотрудник для бизнеса, клиентов, продаж и коммуникаций.

/setdescription
ClientPlatform помогает владельцу и команде вести клиентов, обращения, записи, программы, продажи и мессенджеры в одном рабочем пространстве.

/setcommands
start - Открыть ClientPlatform
admin - Открыть админку бизнеса
mybot - Управление моим Telegram-ботом
privacy - Конфиденциальность и данные
mydata - Экспортировать мои данные
deletemydata - Удалить мои данные
cancel - Отменить текущий шаг
