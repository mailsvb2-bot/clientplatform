# Creative image discoverability slice

This slice improves owner access to the existing visual generation capability without replacing the generator.

## User path

- Keep the owner home screen result-first with one primary action.
- Expose `🎨 Создать картинку` on the second-level owner menu and inside promotion/content surfaces.
- Let an authorized owner describe an image in ordinary language.
- Reuse the existing Visual Gateway and saved business Brand DNA.
- Require an explicit confirmation immediately before a potentially paid generation call.
- Keep the generation idempotency key stable for the same confirmed request.
- Keep roles without promotion-management permission away from the paid creative entry.

## Non-goals

- No new generator/provider implementation.
- No replacement of the existing ad Creative Studio.
- No new business-data store or second decision brain.
- No production deployment in this slice.
