# ClientPlatform / А1

> **Статус:** самостоятельный новый продукт в стадии безопасной трансформации из импортированного baseline Метротерапии.

А1 — мультитенантная платформа и цифровой сотрудник для специалистов, самозанятых и малого бизнеса. Пользователь должен без программирования получить персональную Telegram-админку, клиентского бота, автопостинг, готовые воронки, выдачу аудио/видео/программ и понятную аналитику.

## Критическое ограничение

Копию запрещено запускать с production-конфигурацией Метротерапии. ClientPlatform не должен использовать её:

- Telegram-токены;
- PostgreSQL и резервные копии;
- YooKassa/Stars credentials;
- webhook и домены;
- object storage;
- systemd units и серверные пути;
- реальные пользовательские данные.

Репозиторий остаётся публичным по решению владельца. Поэтому реальные секреты, `.env`, DSN, ключи, дампы и пользовательские данные запрещены в GitHub, Actions logs и artifacts.

## Порядок развития

1. Безопасная исходная точка и secret audit.
2. Мультитенантное ядро: `Business`, `BusinessMember`, роли, tenant isolation.
3. Центральная Telegram-админка каждого специалиста.
4. Универсальная выдача аудио, видео и программ.
5. Персональные managed bots.
6. Telegram Mini App.
7. Автопостинг и готовые воронки.
8. ВКонтакте и MAX.

Первый обязательный вертикальный сценарий описан в каноне. До его полного прохождения нельзя размывать проект десятками отраслей и интеграций.
